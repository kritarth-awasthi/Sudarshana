# Sudarshana — IoT Safety Wearable

Wearable panic-detection device with automatic GPS SOS transmission.

## How it works
1. User activates panic trigger
2. GSM SIM module auto-transmits SOS SMS with live GPS coordinates
3. Emergency contacts receive location in under 60 seconds
4. Companion Android app shows real-time tracking

## Stack
Embedded C · GSM Module · GPS · Kotlin · Android SDK
